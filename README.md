# Teleproxy Installer

🌐 **Язык:** Русский | [English](README_EN.md)

Автоматический установщик и менеджер **Teleproxy** — высокоскоростного MTProto прокси нового поколения с защитой от DPI, маскировкой Fake-TLS и поддержкой Direct-to-DC. Он полностью заменяет устаревший MTProxy. Базируется на проекте [teleproxy/teleproxy](https://github.com/teleproxy/teleproxy).

## ✨ Возможности

### 🚀 Установка
- **Быстрая загрузка** — скрипт больше не компилирует код из исходников! Он автоматически определяет архитектуру (`amd64`/`arm64`) и скачивает оптимизированный бинарник.
- **Интерактивная настройка** — пошаговый мастер с выбором порта, TLS-домена и интерфейсов.
- **Новая система конфигурации** — автоматическая генерация современного `config.toml`.
- **Автоопределение IPv4** — внешний IP определяется автоматически через несколько сервисов.
- **Systemd-сервис** — автозапуск при перезагрузке, управление через systemctl (`teleproxy.service`).
- **Двуязычный интерфейс** — поддержка русского и английского языка (выбирается при установке).

### 🔒 Безопасность и обход блокировок
- **Fake-TLS** — трафик на 100% маскируется под обычный защищенный HTTPS-переход (браузерный TLS 1.3).
- **Direct-to-DC mode** — прямое подключение к Дата-Центрам Telegram без посредников (zero-config, не требует скачивания списков серверов).
- **Продвинутая обфускация** — динамическое изменение размеров пакетов (DRS), защита от replay-атак.
- **Генерация секретов** — автоматическое создание стойких паролей при отсутствии пользовательского ввода.

### 🛠️ Управление (`teleproxy-ctl` CLI)
После установки в системе появится мощная утилита `teleproxy-ctl`:

| Команда | Описание |
|---------|----------|
| `teleproxy-ctl status` | Статус сервиса + ссылки подключения |
| `teleproxy-ctl start` | Запуск сервиса |
| `teleproxy-ctl stop` | Остановка сервиса |
| `teleproxy-ctl restart` | Полный перезапуск |
| `teleproxy-ctl reload` | **(NEW)** Перезагрузка конфигов "на лету" без разрыва соединений |
| `teleproxy-ctl logs` | Просмотр логов в реальном времени |
| `teleproxy-ctl links` | Показать QR-коды и ссылки подключения |
| `teleproxy-ctl info` | Детальная информация о конфигурации и пути к файлам |
| `teleproxy-ctl stats` | Статистика по соединениям в формате Prometheus |
| `teleproxy-ctl update` | **(NEW)** Проверить и принудительно установить обновления проекта Teleproxy |

### 📦 Обслуживание
- **Автообновление (Cron)** — скрипт сам раз в 3 дня проверяет новые релизы `teleproxy` на GitHub и обновляет бинарник почти без даунтайма.
- **Полная деинсталляция** — `./mtproxy.sh uninstall` вычищает всё: сервис, cron-задачи, конфиги из `/etc` и сами бинарники.

## 📋 Использование

**Установка:**
```bash
bash <(wget -q -O - https://raw.githubusercontent.com/EikeiDev/mtproxy-installer/refs/heads/main/mtproxy.sh)
```

**Управление:**
```bash
teleproxy-ctl status
teleproxy-ctl links
```

**Удаление:**
```bash
bash <(wget -q -O - https://raw.githubusercontent.com/EikeiDev/mtproxy-installer/refs/heads/main/mtproxy.sh) uninstall
```

## 📌 Требования

- **ОС:** Debian / Ubuntu (apt), CentOS, AlmaLinux, Rocky Linux, macOS
- **Архитектура:** x86_64 или aarch64 (ARM64)
- **Права:** root или sudo
- **Зависимости:** `curl`, `xxd`
